# Product Manager Skills

沉淀产品工作中与 AI 协作的方法，按工作流查找和使用。

| 工作环节 | Skill | 用途 |
| --- | --- | --- |
| 用户研究 | [用户旅程图](research/user-journey-analysis/SKILL.md) | 梳理用户场景、行为、痛点和产品机会，制作旅程图。 |
| 上线与迭代 | [用户行为指标与看板](analytics/user-behavior-tracking/SKILL.md) | 设计用户规模、使用频率、功能行为和转化指标，按需梳理埋点与看板。 |
| 上线与迭代 | [行为监测系统](analytics/tracktrack-behavior-monitor/SKILL.md) | 为已有产品设计并实现行为采集、热力图、轨迹回放和数据看板。 |

每个目录包含对应的 `SKILL.md` 和所需参考文件。将对应目录提供给支持 Skill 的 AI 工具，结合产品背景和任务目标使用。
