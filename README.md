# Product Manager Skills

沉淀产品工作中与 AI 协作的方法，按工作流查找和使用。

| 工作环节 | Skill | 用途 |
| --- | --- | --- |
| 用户研究 | [问卷设计](research/questionnaire-design/SKILL.md) | 根据研究目标设计、优化和检查用户调研问卷。 |
| 用户研究 | [用户旅程图](research/user-journey-analysis/SKILL.md) | 梳理用户场景、行为、痛点和产品机会，制作旅程图。 |
| 上线与迭代 | [埋点设计](analytics/tracking-design/SKILL.md) | 根据产品原型梳理埋点需求，生成 Excel 埋点文档。 |
| 上线与迭代 | [数据指标与看板设计](analytics/user-behavior-tracking/SKILL.md) | 梳理上线后监测指标、统计口径、埋点与看板需求。 |

根据任务目标查看对应 Skill，并向 AI 提供产品背景和已有资料。
