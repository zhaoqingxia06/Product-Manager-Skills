# 可视化交付

- 用户指定格式、布局、字体和风格优先；无指定时，横向排列阶段，纵向排列六个维度，顶部放角色、场景与目标，底部放图例与来源。
- 单页 16:9 仅用于内容可读的横向演示；内容过密时将总览与机会验证分开呈现，不擅自删去已确认内容。
- 情绪曲线使用标明尺度的独立行，与阶段对齐；未知点留空，假设与实证用图例区分。
- 场景插画按需添加，每格一个关键瞬间；默认简洁手绘线条，仅保留解释行为和产品作用的人物、动作与物件。
- 画面与文字中的朝向、持物、设备状态和事件顺序一致；尚未取餐时不画已拿到餐品。
- 需要生成插画时使用可用图像生成工具，并检查实际输出；需要 PPTX 时使用可用演示文稿技能。
- 要求“插画为图片、其余可编辑”时，标题、正文、气泡及屏幕文字均用独立文本；清除位图中的对应文字，不用整页截图代替可编辑内容。
- 导出后渲染检查字号、换行、对齐、裁切、图像比例、曲线与图例；PPTX 另核对字体、页数及文字和图片的实际独立可编辑性。
