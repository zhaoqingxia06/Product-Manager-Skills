08 下一步重点验证

把概念好评，转化成可观察的使用证据

按功能列出要找谁、验证什么、观察什么。以下是研究计划，尚未被本问卷验证。

  1. 手表转写：是否真的比掏手机更快、更方便？

    找谁：有临时沟通需求的手表用户，兼顾未戴手表者。

    怎么测：在突然说话、双手占用、窗口办事任务中，对照手机与手表。

    观察：启动耗时、信息读懂率、抬腕负担，以及用户是否主动选择手表。

  2. 声音识别：哪些问题会让用户再次关闭？

    找谁：重点复访曾关闭手机识别者，并对照仍开启者。

    怎么测：连续多日试用；覆盖手机不在身边、到访提醒等实际可支持场景。

    观察：误报、漏报、耗电、打扰、关闭原因，以及手机与手表如何分工。

  3. 听力测试：谁适合测，测完能否采取行动？

    找谁：补招担心听力变化且具备耳机佩戴条件的人；区分已有专业检测经历。

    怎么测：完整走通佩戴、测试、阅读结果与后续建议；另行验证结果可靠性。

    观察：完成率、结果理解、复测动机和下一步行动；核实拒测来自无需求还是不适用。

  4. 辅助听力：愿意试的人，体验后是否真的受益？

    找谁：优先邀请说不清价值但愿试的16人，并对照高认可者和低意愿者。

    怎么测：分别评估实际支持的面对面、通话、媒体场景，对照原有解决方式。

    观察：听懂程度、噪声感受、舒适度，以及新鲜感过后是否自发复用。

  5. 购买验证：功能是否会改变真实的产品选择？

    手表：固定品牌、价格和其他配置，对照有无功能，验证品牌选择影响能否转为购买选择。

    耳机：设置仅测听、仅辅听、双功能与无功能方案，在明确价格下进行取舍，拆分各项增量价值。

    观察：产品选择、放弃原因和可接受价差，避免把整机预算当成单功能溢价。

  6. 补样与证据：填补轻度困扰人群和真实场景信息

    补谁：当前样本中不足的轻度听力困扰者、不同耳机经验者与佩戴条件不同者。

    补什么：最近一次真实场景、发生频率、影响程度、现有方案及不足；保留反例。

    决策用途：区分“概念看起来不错”和“有明确、反复发生的需求”；体验验收目标在测试前约定。
