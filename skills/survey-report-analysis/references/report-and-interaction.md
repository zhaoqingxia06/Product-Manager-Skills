# HTML 报告与验收
使用自包含 HTML/CSS/JS，不依赖 CDN；图文结合、简洁蓝色、直接标注数字，有意义处配短洞察，选用清晰条形图、表格或矩阵。图表附近标原题及人数、比例、分母和必要口径；原题不可得则明确标注。样本、适用范围及限制可见。移动端友好、文字对比清晰、支持键盘和焦点，避免只靠颜色辨别。
筛选总计最多5项；同维度 OR、跨维度 AND；条件显示、单项取消和清空；空集明确提示，各题分母根据有效作答重算；筛选后全样本叙述隐藏或明确标注。n<30 提示谨慎不等于其他样本可靠。离线文件若嵌入逐人答卷，去名仍可能重识别：明确披露；分享版不嵌逐人数据并检查细分组合，必要时限制交互。
交付前检查总数、分子、分母、比例与图表一致；人工复核若干单题、跳题、多选和交叉；原话可回溯；全样本、单维多选、跨维组合、取消、清空、零样本分别检查；离线打开并检查桌面和窄屏；说明未能执行的验证。不得声称已执行未运行的测试。

交互入口验收：基本画像图表中的条目本身必须是可键盘操作的筛选按钮，点击选项立即刷新其他图表；不接受只在页面顶部提供一组独立筛选按钮。选中明显高亮，再次点击取消；确保当前筛选后为零的未选项仍能点击，以支持同维度 OR。保留页面位置，状态条只展示已选条件、人数和清除。

**强制合表规则：** 同一研究问题或同一组可比数据，若一张表即可清晰展示和比较，必须合并成一张表，不拆成多个图表或重复呈现；表格清楚标明原题、指标、人数、比例和分母，并支持所需的图内点击筛选与联动。仅当一张表无法清晰表达不同维度或会明显损害可读性时才拆分；验收时检查是否存在可以合并的图表。
