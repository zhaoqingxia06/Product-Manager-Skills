# 数据与方法
识别分析单位、一人多份、重复标识、问卷版本及有效作答范围；不能确定重复时标注疑点，不自动剔除。区分跳题、不适用、缺失和无效；分母按题及子群动态确定。单选统计人数/有效答题人数；多选按选项统计去重人数/该题有效人数，合计可超过100%。保留互斥冲突并做敏感性检查。
根据研究目的选择背景、经历、场景、问题、态度之间有解释意义的交叉，显示各组样本量及分子分母；多选组别可能重叠。小组展示人数并谨慎表述，探索性关联不得认定因果；非随机样本不得推及总体。开放题逐条阅读、归纳主题并回看原话，明确编码可重叠及统计单位；保留少数重要反例并去识别。题目或编码无法可靠判断则不计算。概念评价、意愿、实际行为、整机预算与功能付费意愿不能相互代替。
