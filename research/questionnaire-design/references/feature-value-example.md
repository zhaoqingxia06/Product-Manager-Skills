# 新功能概念价值验证问卷（脱敏案例）

本案例根据实际问卷改写：隐藏产品与功能名称、研究对象的敏感属性及全部个人信息；功能、场景和选项为通用化示例，不含受访者回答。

## 研究目标

了解用户对多项新功能的感知价值、使用意愿、适用场景、使用顾虑及其对购买决策的影响，为功能规划提供参考。评价针对功能介绍后的预期，不代表实际使用效果。

## 设计结构

1. **使用背景**：了解现有设备、使用频率和相关工具使用经历，为人群对比提供依据。
2. **逐项验证功能**：简述功能 A 的作用，再问感知价值、使用意愿、使用场景和顾虑；以同样结构评价其他功能。
3. **跨设备价值**：针对跨设备功能，比较新设备与现有设备的使用偏好和适用条件。
4. **购买决策**：分别了解某功能对设备选择的影响，以及包含多项功能的整机价格接受范围。
5. **后续访谈**：询问参与意愿，联系方式选填并说明用途。

## 示例题目（改写）

**功能说明**：假设设备 A 可以独立完成某项原本需要设备 B 才能完成的任务。

1. 你认为设备 A 支持该功能对你有多大用处？【单选】
   - 很有用／有点用／用处不大／完全没用／需要实际体验后才能判断
2. 如果设备 A 支持该功能，你有多愿意使用？【单选】
   - 非常愿意／比较愿意／不太愿意／完全不愿意／需要实际体验后才能判断
3. 你可能在什么情况下使用该功能？【多选，最多 3 项】
   - 外出办事时／工作或学习时／双手忙碌时／设备 B 不在身边时／想快速完成任务时／暂时没有使用场景／其他，请填写：___
4. 与设备 B 相比，你在什么情况下更愿意使用设备 A 的该功能？【多选，最多 3 项】
   - 设备 B 不在身边／不方便拿出设备 B／设备 B 正在处理其他任务／需要快速查看或操作／想不到更方便的情况／其他，请填写：___
5. 哪些因素会影响你使用？【多选，最多 3 项】
   - 效果不准确／操作复杂／续航缩短／隐私顾虑／使用不方便／觉得用不上／没有顾虑／其他，请填写：___
6. 购买设备 A 时，是否支持该功能会多大程度影响你的选择？【单选】
   - 影响很大／有一定影响／影响较小／没有影响
7. 如果一台设备同时支持功能 A 和功能 B，你最多接受的整机价格是多少？【单选】
   - 按产品实际价位设置互斥区间／不考虑购买

## 使用提示

- 场景、顾虑和价格区间应依据具体功能和研究对象重写；无经历或不适用应有相应答案或跳题。
- 为不同功能分别问价值和意愿；整机价格题只能用于分析组合产品，不能拆作单个功能的付费意愿。
- 将价值、意愿、购买影响分别分析；自报意愿不是实际行为，后续可用体验测试或行为数据验证。
